# 市场高低点查询 App

本地 Web App，用于查询指定 A 股/ETF 代码或美股 ticker 在所选日期区间内的日线最高点和最低点。默认代码为 `513100`，默认区间为最近一年。

## 启动

```powershell
npm start
```

然后打开：

```text
http://localhost:3000
```

如需换端口：

```powershell
$env:PORT=3001; npm start
```

## 功能

- 修改 6 位 A 股代码或美股 ticker，例如 `NET`、`QQQ`、`AMD`
- 常用代码预设：`588000`、`513100`、`NET`、`QQQ`、`AMD`
- 修改开始日期和结束日期，也可以一键选择最近 1/3/5/8/10 年历史区间
- 展示区间最高价、最低价、最新收盘价、交易日数
- 导入行情后立即按“波浪确认波动”阈值计算并标注波浪高点和波浪低点；小于阈值的波动不计入波浪，阈值可随时调整并实时刷新历史曲线；图上同时标注用于确认该高低点的触发价格点
- 支持在主图切换“波浪模型”和“近端高点阶梯指标”；每次导入行情后默认显示波浪模型高低点，切换到近端高点阶梯指标后会改为标注近端高点和阶梯买入触发低点，并显示该指标使用的参数
- 支持 `MA-RSI 波段模型`（`ma-rsi-band`）：按快慢均线趋势、RSI 超跌/过热和 ATR 高波动条件每日计算目标仓位；切换到该模型后显示 MA/RSI/ATR 参数，并在历史图和回测图上标注加仓/减仓信号
- 模拟交易回测的“策略预设”会随当前指标模型过滤：波浪模型只显示波浪策略，近端高点阶梯指标只显示阶梯策略，MA-RSI 波段模型只显示 MA-RSI 策略；选择预设后会立即把该预设的参数数值填入界面
- 如果已经跑过回测，调整波浪阈值会同步重算模型交易，确保买入时引用的阶段高点和图上的最新波浪计算一致
- 如果已经跑过回测，调整近端高点阶梯指标参数会同步重算模型交易，确保图上点位和交易逻辑一致
- 展示可放大、横向滚动的收盘价走势图，并标出全区间最高点、最低点、按阈值确认的波浪高低点，以及确认这些波浪点时用到的触发价格
- 展示最近 30 个交易日关键数据
- 模拟账户历史回测：可设置初始现金、每笔交易费、波浪确认波动、买入回撤阈值、目标仓位、较最近买入价上涨卖出阈值、减仓比例；每笔交易费默认 5 元，模型买入/卖出和全仓基准首日买入都会扣费并记录总费用；默认从阶段高点回撤 5% 加仓到 30%，10% 加仓到 60%，15%/20%/25%/30% 加仓到 100%；默认上涨 5% 减仓 10%，上涨 15% 减仓 30%，上涨 30% 减仓 60%，上涨 50% 减仓 100%
- 每一条买入档位、卖出档位和风控平仓规则都可以单独启用或停用
- 风控平仓参数可调：参考高点天数、连续未突破天数、平仓比例；默认持仓后连续 5 个交易日未突破前 6 日高点时，剩余持仓 100% 平仓
- 点击“开始测试”后逐日回放账户现金、持仓、收益、最大回撤和交易日志；回测可以使用导入数据全区间，也可以随机选择开始时间并测试 1/2/3/4/5 年窗口
- 比较模型策略和全仓持有基准的收益、最大回撤、交易总费用，以及模型相对全仓的回撤差异
- 并行计算“第一天全仓买入后一直持有、不卖出”的基准收益，并展示模型收益、全仓持有收益、超额收益和 XY 对比曲线
- 展示全宽回测价格波动曲线，支持最高 12 倍放大、缩小、横向滚动，标出每次模型买入/卖出点和每个确认出的波浪高点；买入标注触发时使用的阶段高点，卖出标注最近一次模型买入价或风控平仓使用的前 6 日高点
- 交易日志只记录模型策略交易；全仓基准只在第一天买入并持有，不生成卖出记录
- 内置 `513100 多周期优化策略` 预设，可一键套用经过 1/3/5/8 年窗口回测筛选的买卖模型

## 513100 多周期优化策略

此版本在 `513100`、有效日线 `2018-08-13` 至 `2026-08-10` 上搜索得到，并分别验证最近 1 年、3 年、5 年、8 年窗口。数据源为本地行情 API，当前 Yahoo 返回的 `2026-08-11` 非正收盘价会被过滤，不参与计算。

使用方法：

1. 启动 App 后查询 `513100`。
2. 在“模拟交易回测”里选择 `513100 多周期优化策略`，点击“套用”。
3. 点击“开始测试”。
4. 如需复现搜索结果，在服务已启动时运行：

```powershell
npm run optimize
```

策略参数：

- 波浪确认波动：`15%`
- 买入：从阶段波浪高点回撤 `5%` 加仓到 `40%`；回撤 `10%` 加仓到 `70%`；回撤 `15%` 加仓到 `100%`
- 卖出：较最近一次模型买入价上涨 `30%` 减仓 `30%`；上涨 `70%` 减仓 `70%`；上涨 `80%` 平掉剩余仓位
- 风控平仓：关闭
- 全仓基准：窗口第一天全仓买入，之后一直持有，不卖出

## 588000 近端高点阶梯指标

这是按“最近几天高点回落后分批买入、按最近买入价反弹后分批卖出”的思路新增的指标族。优化脚本会同时测试原始想法和参数搜索后的版本。

指标定义：

- 近端高点：最近 `N` 个交易日内的最高价
- 首次买入：收盘价较近端高点回落达到 `entryDrop%`
- 继续加仓：之后每多回落 `ladderDrop%`，继续加仓
- 加仓方式：每次把目标仓位增加 `buyAdd%`，最高不超过 `maxTarget%`
- 卖出方式：价格较最近一笔模型买入价上涨 `sellRise%`，减仓 `sellReduce%`
- 深跌保护：若从锚定高点回落达到 `stopLoss%`，按 `stopReduce%` 平仓

用户原始参数回测：

- 最近 `3` 天高点
- 回落 `2%` 买入 `20%`
- 之后每下跌 `2%` 加仓 `20%`
- 较最近买入价上涨 `2%` 卖出 `20%`
- 无深跌保护

| 窗口 | 模型收益 | 模型最大回撤 | 全仓收益 | 全仓最大回撤 |
| --- | ---: | ---: | ---: | ---: |
| 1 年 | 31.97% | 21.03% | 66.36% | 30.20% |
| 3 年 | 39.34% | 21.03% | 86.67% | 31.85% |
| 5 年 | 1.78% | 29.64% | 11.96% | 59.05% |
| 上市以来/8 年窗口 | 11.58% | 28.30% | 27.44% | 59.64% |

针对 `588000` 搜索后的近端高点阶梯优化参数：

- 最近 `5` 天高点
- 回落 `2%` 首次买入
- 之后每多下跌 `4%` 加仓
- 每次加仓 `30%`，最高 `100%`
- 较最近买入价上涨 `4%`，减仓 `25%`
- 从锚定高点回落 `25%` 时，剩余持仓 `100%` 平仓
