# A股高低点查询 App

本地 Web App，用于查询指定 A 股/ETF 代码在所选日期区间内的日线最高点和最低点。默认代码为 `513100`，默认区间为最近一年。

## 启动

```powershell
npm start
```

然后打开：

```text
http://localhost:3000
```

如需换端口：

```powershell
$env:PORT=3001; npm start
```

## 功能

- 修改 6 位股票代码
- 修改开始日期和结束日期
- 展示区间最高价、最低价、最新收盘价、交易日数
- 导入行情后立即按“波浪确认波动”阈值计算并标注波浪高点和波浪低点；小于阈值的波动不计入波浪，阈值可随时调整并实时刷新历史曲线；图上同时标注用于确认该高低点的触发价格点
- 如果已经跑过回测，调整波浪阈值会同步重算模型交易，确保买入时引用的阶段高点和图上的最新波浪计算一致
- 展示可放大、横向滚动的收盘价走势图，并标出全区间最高点、最低点、按阈值确认的波浪高低点，以及确认这些波浪点时用到的触发价格
- 展示最近 30 个交易日关键数据
- 模拟账户历史回测：可设置初始现金、波浪确认波动、买入回撤阈值、目标仓位、较最近买入价上涨卖出阈值、减仓比例；默认从阶段高点回撤 5% 加仓到 30%，10% 加仓到 60%，15%/20%/25%/30% 加仓到 100%；默认上涨 5% 减仓 10%，上涨 15% 减仓 30%，上涨 30% 减仓 60%，上涨 50% 减仓 100%
- 每一条买入档位、卖出档位和风控平仓规则都可以单独启用或停用
- 风控平仓参数可调：参考高点天数、连续未突破天数、平仓比例；默认持仓后连续 5 个交易日未突破前 6 日高点时，剩余持仓 100% 平仓
- 点击“开始测试”后逐日回放账户现金、持仓、收益、最大回撤和交易日志
- 比较模型策略和全仓持有基准的收益、最大回撤，以及模型相对全仓的回撤差异
- 并行计算“第一天全仓买入后一直持有、不卖出”的基准收益，并展示模型收益、全仓持有收益、超额收益和 XY 对比曲线
- 展示全宽回测价格波动曲线，支持最高 12 倍放大、缩小、横向滚动，标出每次模型买入/卖出点和每个确认出的波浪高点；买入标注触发时使用的阶段高点，卖出标注最近一次模型买入价或风控平仓使用的前 6 日高点
- 交易日志只记录模型策略交易；全仓基准只在第一天买入并持有，不生成卖出记录

行情数据来自东方财富日 K 接口，仅用于本地查询和展示。
